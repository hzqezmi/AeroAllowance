# AeroAllowance

Android app for estimating excess baggage fees, built with Java for ICT602.

## How to run

1. Open this folder in Android Studio.
2. Use the bundled JDK and install Android SDK Platform 36.
3. Let Gradle sync, then select an emulator or Android phone (Android 8.0 or newer).
4. Click Run.
