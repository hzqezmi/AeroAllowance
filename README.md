# AeroAllowance

Flutter app for estimating excess baggage fees for ICT602.

## How to run

1. Open this folder in Android Studio with the Flutter plugin installed.
2. Run `flutter pub get`.
3. Select the Pixel 8 emulator and run `lib/main.dart`.

Terminal option: `flutter run`, then choose Pixel 8 if prompted.

Build an Android APK with `flutter build apk --debug`.
